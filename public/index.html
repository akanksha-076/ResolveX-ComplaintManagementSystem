Why Use ResolveX?

Built on a scalable polyglot persistence architecture combining MySQL and MongoDB.

Easy Reporting

Submit complaints online with category, location, priority, and instant SLA target tracking inside an atomic MySQL transaction.

Real-Time Progress & Audit

Automated triggers capture every status transition in MySQL while MongoDB stores discussion comments and live activity timelines.

Analytics & Data Warehouse

Run an integrated ETL pipeline to populate star-schema warehouse facts, archive Data Lake snapshots, and monitor SLA metrics.

Enterprise DBMS Security

Protected by bcrypt password hashing, signed JWT tokens, Role-Based Access Control (RBAC), and parameterized SQL injection shields.

For Everyone on Campus

Tailored workflows backed by fine-grained RBAC permissions.

Students

Submit issues, search personal complaint history, collaborate via comments, and rate resolved complaints.

Department Staff

View assigned departmental queues, respond to student comments, and update resolution progress safely with optimistic locking.

Administrators

Triage complaints, run cursor-based overdue escalation, inspect EXPLAIN query plans, manage RBAC roles, and execute ETL analytics.
